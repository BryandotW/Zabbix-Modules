# Zabbix-Modules
## 模块介绍：

### cpu_memory_reporter：
通过过滤主机组/主机，
时间过滤选项有：最近5分钟、最近15分钟、最近30分钟、最近1小时、最近3小时、最近6小时、最近12小时、最近1天、最近2天、最近3天、最近4天、最近5天、最近6天、最近7天、最近15天、最近30天、最近60天、最近90天、最近120天、最近150天、最近180天
可选择的排序方式：
HostID/CPU使用率峰值/CPU使用率均值/CPU使用率中位数/1分钟CPU负载峰值/1分钟CPU负载均值/1分钟CPU负载中位数/5分钟CPU负载峰值/5分钟CPU负载均值/5分钟CPU负载中位数/15分钟CPU负载峰值/15分钟CPU负载均值/15分钟CPU负载中位数/内存使用率峰值/内存使用率均值/内存使用率中位数

获取内容如下：
HostID、主机名称(Visible Name)、主机名(Host name)、所属群组、CPU核数、内存总量(GB)、CPU使用率峰值(%)、CPU使用率均值(%)、CPU使用率中位数(%)、1分钟CPU负载峰值、1分钟CPU负载均值、1分钟CPU负载中位数、5分钟CPU负载峰值、5分钟CPU负载均值、5分钟CPU负载中位数、15分钟CPU负载峰值、15分钟CPU负载均值、15分钟CPU负载中位数、内存使用率峰值(%)、内存使用率均值(%)、内存使用率中位数(%)

### custom_host_filter：
按主机群组、主机名称、IP地址、端口、接口启用状态、接口监控类型、接口可用性状态，去灵活筛选主机

### id_finder：
快捷选择并提取主机、群组、监控项及触发器的 ID 号

### id_resolver：
通过 ID 号反向获取主机、群组、触发器及监控项的详细信息
