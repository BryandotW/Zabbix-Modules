php-fpm.conf 增加：
request_terminate_timeout = 600

---------------------------------------------------------
zabbix的nginx.conf文件下
location ~ [^/]\.php(/|$) 修改这三个参数为：
                fastcgi_connect_timeout         600;
                fastcgi_send_timeout            600;
                fastcgi_read_timeout            600;



如果有nginx反向代理：反向代理的conf文件下 增加：
location / {

		proxy_connect_timeout 600s; # 与前置建立连接超时
		proxy_send_timeout    600s; # 前置向后端发送数据超时
		proxy_read_timeout    600s; # 前置等待后端响应的最长超时(核心控制项)
}
